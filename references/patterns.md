# 草稿毛病对照表（37 条）

诊断或修复草稿时读本表，只查与草稿毛病对应的分类，不要整篇套用。命中项按「坏例 → 改法」落进七段；标〔内建〕的毛病已由运行流程兜住，只需确认成品没复发，不必额外改写。

分类沿用流程第 3 步：能归目的/事实/假设/惯例/约束的先归类，再用本表校准改法。
